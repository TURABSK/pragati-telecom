📁 Supported File Types & Technical Specifications

Smart Form Filler supports the standard file formats used across West Bengal and Indian national portals:

PDF

Adobe Portable Document Format (.pdf)

Multi-page native vector PDFs, scanned land deeds, and government forms. Supports interactive AcroForm extraction.

JPG / JPEG

Joint Photographic Experts Group (.jpg)

Standard digital camera and smartphone captures. Recommended resolution: 200–300 DPI for clear text alignment.

PNG

Lossless flatbed scanner output. Provides maximum edge sharpness for printed form borders and fine table gridlines.

WEBP

Modern Web Picture (.webp)

Compact web images with high compression efficiency, ideal for fast uploads over mobile network connections.

❓ Frequently Asked Questions (AI Smart Form Filler)

What is an AI Smart Form Filler?
An AI Smart Form Filler is a digital productivity tool that analyzes PDF documents and scanned application images to identify fillable blanks, lines, and checkboxes, allowing users to type information directly onto the document and download a completed PDF.
Can I fill a PDF form online without Adobe Acrobat?
Yes. Smart Form Filler operates entirely in your web browser. You can open any PDF, type text into fillable areas, toggle checkboxes, and download the finished PDF without installing Adobe Acrobat or any other desktop software.
Can the tool work with scanned forms, photocopies, and mobile camera photos?
Yes. In addition to native PDF files, you can upload JPG, PNG, and WebP images. You can detect fields automatically using the AI vision scanner or draw custom fillable boxes anywhere on the image.
Can I manually add a form field if the automatic detector misses it?
Yes. Switch to the Draw ('আঁকুন') mode in the toolbar and click and drag directly on the document canvas to create a new fillable text box or checkbox at any precise location.
Can I move and reposition detected fields?
Yes. Switch to the Edit ('এডিট') mode, click any field box to select it, and drag it to reposition it exactly over printed lines or table columns.
Can I resize a field box to fit an underline or table cell?
Yes. In Edit mode, selecting a field displays eight circular resize handles around its perimeter. Drag any handle to expand or contract the field width and height.
How do I fill checkbox and radio option fields?
In Fill ('পূরণ') mode, simply click on any checkbox box to toggle it on or off. You can select your preferred check glyph (✓, ✔, ✗, ●) in the Settings tab.
Can I download the completed filled PDF?
Yes. Clicking the 'PDF ডাউনলোড' button compiles your entered text and checkboxes into a standardized vector PDF using client-side PDF-Lib and initiates an immediate file download.
Does Smart Form Filler work on mobile phones and tablets?
Yes. The interface is fully responsive on modern mobile browsers. However, for precision document alignment and high-volume table filling, a desktop or laptop with a mouse provides the most comfortable workflow.
What happens if automatic AI detection misses a field?
You are never blocked by AI errors. You can use the Draw mode to manually draw missing fields in seconds, or click the '+ ফিল্ড যোগ করুন' button in the sidebar to add a field and position it manually.
