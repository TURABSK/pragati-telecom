⚙️ How Our Tools Work: Client-Side vs. AI OCR Processing

To maintain transparency, we clearly separate how your files are handled based on the tool you select:

Model 1: 100% In-Browser Local Tools

Local Client Processing

The Photo Studio, Smart Multi-Card Studio, PDF Compressor, Visual PDF Editor, and Cash Tally run entirely inside your browser using HTML5 Canvas, PDF-Lib, Tesseract.js Web Workers, and WebAssembly.

✔ Files never leave your computer or phone.
Model 2: Secure Serverless AI OCR

Cloudflare Worker AI Processing

When creating multi-column searchable PDFs from scanned documents in Searchable PDF Maker, recognition is executed through secure serverless Cloudflare Worker endpoints. No personal API keys are required from users.

✔ 100% key-free and private for users.

🔒 Privacy, File Handling & Security

Pragati Telecom does not operate a file-storage cloud backend or retain user documents. Once you close your browser tab, all temporary memory buffers (blobs and canvas contexts) are immediately freed by your browser. ❓ Frequently Asked Questions (FAQ)

Find quick, honest answers to common questions about our platform, features, and processing methods:

Are the tools on Pragati Telecom free to use?
Yes. All 7 digital tools on Pragati Telecom are freely accessible directly through your web browser without paywalls or mandatory account registrations.
Are my personal files and photos uploaded to Pragati Telecom servers?
No. Pragati Telecom does not have a server database or file-storage backend. When you use tools like the AI Photo Studio, Smart Multi-Card Studio, or PDF Compressor, all computations occur locally inside your browser's memory (RAM).
Do I need an API key to use AI OCR features?
No. All AI OCR operations (such as multi-column Bengali and English text extraction in Searchable PDF Maker and Drag & Drop PDF Maker) are handled securely through Pragati Telecom's serverless Cloudflare Worker API. You never need to supply, manage, or paste personal API keys.
Does every tool require an active internet connection?
Once the initial web page and libraries (like PDF.js, PDF-Lib, and Cropper) load in your browser, the local tools (Photo Studio cropping, Smart Card alignment, and PDF Compression) can execute entirely offline without sending network requests. Only the AI OCR features require an internet connection to contact Google's API.
Can I use these tools on mobile devices or tablets?
Yes. The portal is fully responsive and works on modern mobile browsers (Google Chrome, Safari, Edge, Firefox). However, for multi-card tray printing and precise PDF visual editing, a desktop or laptop with a connected printer offers the optimal experience.
Can cyber cafe and CSC operators use these tools for customer jobs?
Yes. Operators are welcome to use our layout and cropping tools to streamline customer print jobs, passport photo sheets, and document resizing, provided the documents processed are legitimate and handled with customer consent.
Is Pragati Telecom an official government portal?
No. Pragati Telecom is an independent digital tool and productivity website developed in Murshidabad. We are not an official government body and do not issue or certify government credentials.
Where can I learn more about data handling, privacy, and terms?
You can read our detailed Privacy Policy, Terms & Conditions, Disclaimer, and About Us pages for comprehensive information.
