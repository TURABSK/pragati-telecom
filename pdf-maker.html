📑 How Drag & Drop PDF Maker Works

When assembling multi-page applications, project reports, or receipts, users frequently need to combine different photos (such as mobile snapshots of marksheets and ID cards) and existing PDF pages into a single organized document. Drag & Drop PDF Maker provides a visual workspace where you can freely arrange pages, set a target file size, and optionally embed searchable Bengali & English text.

🖱️

Sortable Page Grid

Powered by Sortable.js — drag and drop any thumbnail card to reorder pages intuitively with real-time numbering.

🎯

Multi-Pass Compression

Dynamically tests 4 JPEG quality passes (85%, 70%, 50%, 35%) to match your chosen target file size (100 KB to 5000 KB).

🤖

Optional AI OCR Layer

Optionally extracts text coordinates using Google Gemini AI and embeds an invisible selectable text layer with Bengali fonts.

⚖️ Local Processing vs. Optional AI OCR (Privacy Difference)

We maintain strict transparency between our two operational modes:

Standard Mode (OCR Unchecked)

100% Client-Side Local: Images and PDF pages are loaded, sorted, compressed, and merged strictly inside your browser RAM. No data is sent across the network.

AI OCR Mode (OCR Checked)

Direct Google API Transmission: Image canvas slices are transmitted via HTTPS POST to Google's Gemini API using your personal API key stored in localStorage.

📋 Step-by-Step Guide

  1. Upload Pages: Click "Select Images / PDF Pages" to upload multiple photos (JPG, PNG, WebP) or existing PDFs.
  2. Reorder Pages: Click and drag any thumbnail card in the grid to place pages in the correct sequence. Delete unwanted pages using the ✕ button.
  3. Set Target Size: Move the Target Size slider (e.g. 500 KB or 1000 KB).
  4. Select OCR Preference: Keep "Make Searchable (AI OCR)" checked if you have entered a Gemini API key, or uncheck it for instant offline local creation.
  5. Generate & Download: Click "Generate Merged PDF" and download the finalized document.

❓ Frequently Asked Questions (PDF Maker)

Can I mix JPEG photos and PDF documents in the same file?
Yes. You can upload multiple JPG photos, PNG screenshots, and existing PDF documents simultaneously. The tool breaks multi-page PDFs into individual sortable cards.
Is the Gemini API key required for creating merged PDFs?
No. The Gemini API key is only required if you check the "Make Searchable (AI OCR)" box. For standard PDF merging and size compression, no API key is necessary.
Where is my Gemini API key stored?
Your key is saved locally in your browser's private storage (localStorage) under pragati_gemini_key. It is never transmitted to Pragati Telecom servers.
How does page reordering work on touchscreens?
On mobile devices and tablets, tap and hold a card briefly, then drag it to your desired position in the grid.
What is the maximum number of pages I can merge?
You can easily merge 20–50 pages on typical laptops and smartphones depending on available browser memory.
