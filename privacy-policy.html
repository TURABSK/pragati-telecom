Privacy Policy

At Pragati Telecom, we believe in complete transparency regarding how digital files, images, PDFs, and API keys are handled when you use our web utilities.

📅 Effective Date: August 30, 2026 🔄 Last Technical Review: August 2026

1. Overview & Core Privacy Principle

This Privacy Policy governs the online tools, utilities, and services provided by Pragati Telecom ("we", "us", or "our"), accessible at https://turabsk.github.io/pragati-telecom/.

Our fundamental engineering principle is client-side data isolation. Unlike conventional cloud document conversion websites that upload your personal documents to remote web servers for conversion and storage, the vast majority of Pragati Telecom tools execute entirely within your web browser’s sandbox memory (HTML5 Canvas, WebAssembly, Web Workers, and JavaScript).

To maintain absolute honesty and compliance with data privacy regulations, we explicitly categorize each tool’s processing behavior below:

3. Local Client-Side Processing Details

For all tools marked as 100% Client-Side:

  • Files selected via the <input type="file"> or drag-and-drop zones are read into your browser using the HTML5 FileReader API or URL.createObjectURL().
  • Document rendering, cropping, scaling, background removal, and compression occur exclusively inside your device's memory.
  • When you download a generated PDF or JPG image, it is generated as a client-side Blob (blob: URL) and saved directly to your local file storage.
  • Pragati Telecom has no server backend, no database, and no server-side file storage for these tools. We never view, collect, or store your documents.

4. Third-Party API Data Transmission (Google Gemini AI OCR)

In tools offering optical character recognition (specifically searchable-pdf.html and pdf-maker.html):

  • User-Supplied API Keys: Pragati Telecom does not provide a public shared API key. Users must supply their own personal Google Gemini API key to activate AI OCR functionality.
  • Data Transmitted: When you click "Generate Searchable PDF" with OCR enabled, canvas image slices of the document are converted to base64 JPEG format and transmitted via an encrypted HTTPS POST request directly to Google’s endpoint at generativelanguage.googleapis.com.
  • Google's Privacy Terms: Data transmitted to the Gemini API is governed by Google’s Privacy Policy and the Google Cloud / Gemini API terms of service.
  • Local Key Storage: Your Gemini API key is stored strictly in your browser's local storage (localStorage.setItem("pragati_gemini_key", ...)). It is never transmitted to Pragati Telecom. You can clear this stored key at any time by clicking the "Logout / Clear API Key" button.

5. Content Delivery Networks (CDNs) & External Assets

To ensure optimal loading speeds and secure library delivery, our website loads open-source JavaScript libraries and fonts from reputable public CDNs:

  • cdnjs (Cloudflare): Serves pdf.js, pdf-lib, jspdf, cropperjs, Sortable.js, and jszip.
  • jsdelivr: Serves @imgly/background-removal and tesseract.js WebAssembly scripts.
  • Google Fonts: Serves the Plus Jakarta Sans typeface stylesheet and the Noto Sans Bengali TrueType font binary for Bengali PDF rendering.

These CDNs may collect standard technical access logs (such as your IP address, browser user-agent, and timestamp) in accordance with their respective privacy policies.

6. Cookies & Tracking Technologies

Current Status: Pragati Telecom does not use tracking cookies, behavioral tracking scripts, or analytics pixels (such as Google Analytics or Facebook Pixel) in its current codebase.

Browser LocalStorage: We utilize browser localStorage solely for functional preferences (storing your user-provided Gemini API key locally on your device).

Future Advertising Disclosures: If third-party advertising partners (such as Google AdSense) are introduced in the future, they may use cookies or web beacons to serve advertisements based on user visits to this and other websites. Users will retain the right to manage cookie preferences and opt out of personalized advertising via Google Ad Settings (https://adssettings.google.com).

7. Data Security & User Responsibilities

While our client-side architecture minimizes data exposure, users must uphold safe digital hygiene:

  • Always access Pragati Telecom over a secure HTTPS connection.
  • When working on public or shared computers (e.g., in cyber cafes or libraries), remember to clear downloaded files from the local Downloads folder and click "Clear API Key" after completing your session.
  • Do not share your personal Google API keys with unauthorized individuals.
